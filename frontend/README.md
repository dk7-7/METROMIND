# GridSentinel Central Terminal Control System

GridSentinel is a state-of-the-art utility incident and outage monitoring system built with React, Vanilla CSS custom variables, and Lucide icons.

## Features

- **Diagnostic Dashboard**: Dynamic progress trackers, critical counts, loads, and incident lists.
- **Incident Manager**: Filter, search, create, update, and resolve utility failure events.
- **Utility Sectors**: Track capacity loads across power, gas, water, and telecom nodes.
- **Outage Planner**: Track active or schedule planned service blackouts.
- **Operator Clearances**: Robust session authorizations and config management.

## Getting Started

### Local Credentials
For diagnostic testing, enter the following default credentials in the Login screen:
- **Email**: `admin@utility.com`
- **Key**: `admin123`

### Development Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the application:
   ```bash
   npm start
   ```
